# Publicação de fotografias adicionais

O site está preparado para mostrar novas fotografias em **Equipamentos e montagem → Galeria dos acessórios complementares**.

Para publicar os arquivos:

1. Extraia o arquivo `Fotos_adicionais_IoT_para_GitHub.zip` fornecido no chat.
2. No GitHub, dentro da raiz do aplicativo `iot-umidade-solo-streamlit`, crie `imagens/galeria_extra/` se necessário.
3. Envie individualmente os arquivos JPEG de `galeria_extra/` para essa pasta (não envie apenas o ZIP).
4. Confirme o commit na branch `main` e atualize o site Streamlit.

A galeria exibe automaticamente apenas as imagens presentes, permitindo adicionar mais fotos gradualmente.
Os acessórios DHT11, PIR, LDR, OLED, relés e bomba **não foram utilizados** no circuito validado, sendo apresentados como componentes disponíveis ou destinados a futuras etapas.
